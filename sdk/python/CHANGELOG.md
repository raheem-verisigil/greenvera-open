# OpenSpace SDK preview release

This preview provides a server-side Python client, local TrustLab runner and optional LangGraph callback integration.

- Python >=3.10
- No mandatory third-party runtime dependencies
- HTTPS required for non-loopback API endpoints
- Customer-run tests; results are submitted as evidence records
- No raw prompt or model-output collection in the SDK's default helper methods

This is a preview integration library, not a production certification, security guarantee or deployment controller.
